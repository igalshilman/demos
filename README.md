# A demo project

## Greeter CLI

A small command-line greeter written in Python.

### Prerequisites

- Python 3 (standard library only; no extra packages needed)

### Usage

```sh
python greeter.py                       # Hello, World!
python greeter.py --name Ada            # Hello, Ada!
python greeter.py --name "Ada Lovelace" # Hello, Ada Lovelace!
python greeter.py --help                # show usage
```

### Running the tests

```sh
python -m unittest discover -s tests -v
```
