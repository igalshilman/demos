# A demo project

Built by the factory.

## Greeter CLI

A small greeter that needs only Python 3 and its standard library.

Run it:

```
python greeter.py
python greeter.py --name Alice
```

The first prints `Hello, World!`, the second `Hello, Alice!`. Use `python greeter.py --help` for usage.
